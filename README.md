# Interactive Quiz Application

## About the Project
The Interactive Quiz Application is a Python-based program that asks multiple-choice questions, checks answers, and calculates the user's final score.

## Features
- Five multiple-choice questions.
- Interactive user input.
- Automatic answer checking.
- Score calculation.
- Final score display.
- Case-insensitive answers (A, B, C, or D).

## Technologies Used
- Python 3

## Concepts Used
- Lists and dictionaries
- Loops
- Conditional statements
- User input
- Variables and score calculation
- String methods

## How to Run
Make sure Python 3 is installed, then run:

```bash
python quiz.py
```

## Sample Output
```text
WELCOME TO THE QUIZ!

Question 1: Which language is used for Python programming?
A. HTML
B. Python
C. CSS
D. SQL

Your answer (A/B/C/D): B
Correct!

Your final score: 5/5
```

*Note: The final score depends on the user's answers.*
